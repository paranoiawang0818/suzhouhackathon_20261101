## 文献检索

用户于本次部署中明确批准启用 Europe PMC 公开接口。当前默认只检索 `SRC:MED`（PubMed 收录记录）且有摘要的文献，返回真实 PMID、期刊、年份、DOI 和摘要。摘要最多保留 1500 字符。界面显示检索入口，论文链接指向 PubMed。

NCBI 直连在腾讯云端曾被重定向到 `misuse.ncbi.nlm.nih.gov` 验证页面；本地同一接口正常。保留 NCBI 接入代码，待解除限制后可通过服务端环境变量 `PUBMED_PROVIDER=ncbi` 切换。可选 `NCBI_API_KEY` 仅由服务端读取。当前默认入口不需要该变量。

检索式由 AI 根据实际问题生成；已有资料标题只用于确认相关试验名称。论文与 PMID 由公开接口实时返回。AI 只整理证据线索，最终医学结论由医学部查证并确认。

## 数据与密钥

任务、已确认知识和个人经验仍保存在当前浏览器 localStorage，键名为 `brand-assistant-prod-v1`。新浏览器没有预置任务。当前版本保留销售和医学部视角切换。

DeepSeek 密钥由腾讯云现有生产环境变量提供。源码归档不包含 `.env.local`。本地运行由 Next.js 自动加载现有 `.env.local`，无需读取或复制其中内容。

## 验证与打包

```sh
npx tsc --noEmit
npx eslint src
node --conditions=react-server scripts/check-pubmed.mjs --live
npm run build
git archive --format=zip -o /private/tmp/brand-assistant-formal-source.zip HEAD
git archive --format=tar.gz -o ../部署包/brand-assistant.tar.gz HEAD
```

只在 `prod` 分支本地提交，不推送远程仓库。将源码 ZIP 上传至原项目的生产环境后，检查平台发布成功，并在正式网址提交示例问题和独立新问题，核对实时 AI、检索式、PMID、检索入口和摘要来源。验收截图、日志和本地过程记录保存在 `deploy/qa/`，不进入源码归档。
