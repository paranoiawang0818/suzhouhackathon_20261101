# 历史归档

| 文件 | 含义 |
|---|---|
| `source/brand-assistant-snapshot.zip` | 答辩备用演示版的只读公开快照，含演示向导、预置任务和模拟样稿 |
| `source/brand-assistant-edgeone-snapshot.zip` | 早期 EdgeOne 适配源码快照，不是当前线上正式版 |

历史源码移除了环境变量文件、依赖、缓存和 Git 元数据。原本地备用目录没有修改，也没有在原仓库执行提交或推送。

历史部署指令包含未采用的独立服务器方案及仅在当时适用的操作限制。当前运行方式见 [运行与部署](../docs/GETTING_STARTED.md)，当前源码位于仓库根目录。
