# 历史路演材料

- [演示视频 MP4](品牌沟通助手_演示视频.mp4)
- [可编辑路演 PPTX](品牌沟通助手_路演.pptx)
- [原始及裁剪截图 ZIP](历史路演截图.zip)

这些材料来自正式版改造前的演示流程，包含模拟角色、预置医学样稿和演示数据。它们用于说明产品想法与页面流程，不代表真实医学人员已经审核、真实医生已经反馈，或当前正式版的全流程验证。

当前正式版已移除预置任务与模拟答复入口，并接入真实文献检索。[最新验收](../../docs/verification.md) 与 [当前架构](../../docs/ARCHITECTURE.md) 单独记录。

浏览器或 GitHub 预览若不能播放大视频，可下载 MP4 后打开。PPTX 为可编辑源文件。
