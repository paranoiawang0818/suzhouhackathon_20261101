# 给队友的阅读说明

这是一份产品设计评审稿，可以直接在 Word 中批注或修改。

## 阅读顺序

1. `医学问询产品设计_v3.docx`：可编辑主文档；PDF 为对应阅读版。
2. 第2节：相对之前方案改变了什么。
3. 第4节及流程图：各环节输入、动作、产出和责任。
4. 第7、8节：首版范围与已有研发如何衔接。
5. 第10节：需要团队补充和确定的事项。

## 最新确认的方向

- AI给医学部提供整理清楚的问题与相关证据，医学人员完成专业查证与答复。
- 医学答复形成后，AI逐项检查原问题是否得到回应，医学人员处理提示并确认答复。
- 销售继续制作交付物；审核方式、自由改写范围及个人Agent能力尚待讨论。
- 企业医学知识及个人／团队经验的基础保存与查找都纳入首版。

## 新旧文档如何使用

v3替代此前v2中与本轮明确需求冲突的业务安排。旧版数据、来源、历史记录和其他工程机制可以复用，具体按第8节调整。不要将旧版“AI自动起草专业答复”或“最终销售材料已经医学审核”的安排继续当作默认产品行为。

本包是文档交付，不代表应用代码已修改，也不代表真实医学用户验证已经完成。可编辑Word、PDF、Markdown和HTML来自同一份正文；PNG及SVG是同一张流程图。

## 方便评审的批注方式
