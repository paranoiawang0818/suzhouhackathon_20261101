## 经用户批准的检索入口调整

NCBI 直连在腾讯云中被重定向至 `misuse.ncbi.nlm.nih.gov`。函数日志确认返回 HTML 验证页面，因此 JSON 解析失败。相同查询在本地能返回正常文献。调整请求序列化、响应格式声明和官方 POST 方式后，云端仍受验证限制。

用户已明确批准：只读排查、匿名诊断和最小修复，随后选择“启用 Europe PMC 备用检索”。最终默认通过 Europe PMC 的公开接口获取 PubMed 收录文献；保留 PMID 与 PubMed 原文链接，并在首页、证据分析与每篇资料中显示检索入口。当前不会反复调用受限制的 NCBI 入口。解除限制后可用服务端 `PUBMED_PROVIDER=ncbi` 切回保留的 NCBI 实现。

Europe PMC 的检索排序与 NCBI 不完全相同。系统结合已有资料标题确认试验名称，论文和 PMID 仍由实时接口返回。来源调整没有改动 DeepSeek 密钥或模型。
